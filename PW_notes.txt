How to run test in playwright
===============================
1. npx playwright test |  headless mode | runs all testcases present in tests folder
2. npx playwright test --headed | run all testcases present in tests folder in headed mode.
3. to open the reports in playwright | npx playwright show-report
4. npx playwright test "filename (example.spec.js)" | run specific file testcases.
5. npx playwright test "filename(example.spec.js)" --headed --project=chromium | run test on specific browser project (chromium, firefox, webkit)
6. npx playwright test "filename(example.spec.js)" --headed --project=chromium --debug | enable and run the       test in debug mode
7. npx playwright test --ui | npx playwright test 'filename example.spec.js' --ui  | allow to runs testcase on testruner

Playwright Architecture explain
1. Playwright client (TestCode)
	webscoket ((Events + commands)
2. playwright core 
3. browser (Browser native protocols)

InPlaywright, Our test code doesn't talk to the browser directly
it talks to playwright core Node.js server using websocket (tech)
That server then talks to the browser using native protocals (CDP/CFP/Webkit)
Because of this, playwright is fast, stable and automatically handles wait and less flakyness.

Locators in playwright

1. css
2. xpath
3. property - element would - id, name, link etc.

page.locator('property/xpath/css') || identify the element.

 	// playwright format
    //to type the data into input field use fill funciton.
    await page.locator('[id="loginusername"]').fill("pavanol"); // css format
    await page.locator('#loginpassword').fill('test@123'); //css format
    await page.locator('//button[normalize-space()="Log in"]').click(); // xpath


    //JS format
    await page.fill('[id="loginusername"]',"pavanol");
    await page.fill('#loginpassword',"test@123");
